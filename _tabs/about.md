Halo! Saya Nadir Nahdi — orang yang hobi utak-atik sistem, ngoprek *home lab* kecil-kecilan di rumah, dan nyobain cara kerja baru bareng AI. Blog ini tempat saya nyimpen catatan eksperimen, trik teknis, dan solusi yang kepake sehari-hari — siapa tahu pas banget juga buat kamu yang lagi ngoprek hal serupa.

Dari kecil saya sudah sering main-main sama komputer. Saya besar di Alkhobar, Saudi Arabia, dan sekarang tinggal di Indonesia. Pengalaman tumbuh di lingkungan yang berbeda-beda itu cukup membentuk cara saya ngadepin masalah — baik pas lagi ngulik di terminal maupun di kehidupan sehari-hari.

Sehari-hari saya kerja pakai Windows dengan Windows Terminal dan WSL. Di rumah, ada laptop bekas yang saya sulap jadi *home lab* pakai Docker buat ngurus DNS jaringan rumah dan otomasi media. Soal ngoding dan bikin proyek pun sekarang udah banyak berubah: saya lebih sering ngerancang arsitektur dan ngarahin AI coding agent seperti Antigravity buat ngebangun dan beresin kerjaannya bareng-bareng.

Di luar layar laptop, saya ayah dari tiga anak yang bikin rumah selalu rame, penuh kejutan, dan kadang ngasih "masalah debugging" versi dunia nyata. 😄

Blog ini sebenarnya saya buat jadi *logbook* pribadi — biar solusi dan catatan ngoprek yang dulu susah dicari nggak ilang gitu aja. Kalau tulisan di sini kebetulan ngebantu kamu juga, ya alhamdulillah banget!

> Kalau lagi nyari saya, kemungkinan besar lagi nongkrong di terminal ngerapihin Docker Compose… atau lagi nyuruh AI agent ngeberesin proyek baru. 😅
