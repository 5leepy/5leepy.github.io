# Nadir Nahdi — Logbook Ngoprek, Homelab, dan AI

[![Build and Deploy](https://github.com/5leepy/5leepy.github.io/actions/workflows/pages-deploy.yml/badge.svg)](https://github.com/5leepy/5leepy.github.io/actions/workflows/pages-deploy.yml)
[![Website](https://img.shields.io/website?url=https%3A%2F%2F5leepy.github.io&label=5leepy.github.io)](https://5leepy.github.io)

Ini repositori sumber untuk blog pribadi saya di **[5leepy.github.io](https://5leepy.github.io)**.

Blog ini saya pakai sebagai *logbook* santai untuk nyimpen catatan ngoprek sehari-hari—mulai dari utak-atik **Windows & WSL**, nyulap laptop bekas jadi **home lab Docker 24/7**, sampai eksperimen ngebangun proyek bareng **AI coding agent**. Niatnya sederhana: biar solusi yang dulu susah dicari nggak hilang begitu saja, dan syukur-syukur bisa kepake juga buat orang lain.

## Topik Utama

* ⚙️ **Windows & WSL** — Setup harian pakai Windows Terminal, PowerShell, dan lingkungan Linux di dalam Windows.
* 🐳 **Home Lab & Docker** — Cerita ngoprek server rumahan *hybrid* (Windows + WSL2), Dockge, Pi-hole, Jellyfin, \*arr stack, dan Tailscale.
* 🤖 **AI-Assisted Building & Workflow** — Catatan merancang dan ngerawat proyek bersama AI agent seperti Antigravity.
